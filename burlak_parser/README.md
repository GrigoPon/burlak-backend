# Burlak Parser

Система разбора ведомостей материалов (BOM) и сверки с операционными картами сборки для автомобильного производства.

Автоматическая обработка всех комплектаций за один запуск. Классификация файлов (операционные карты / служебные), безопасное нечёткое сравнение номеров, ZIP-разделение многолистовых файлов с полным сохранением форматирования, параллельное выполнение.

Модульная архитектура на классах-сервисах, готовая к использованию как CLI, так и программно.

---

## Установка

```
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
pip install xlrd
```

Зависимости: openpyxl, xlsxwriter, tqdm.

---

## Использование

```
python -m burlak_parser.main --bom "BOM.xlsx" --cards "./cards/" [OPTIONS]
```

### Параметры

| Параметр | Кратко | Описание |
|----------|--------|----------|
| `--bom` | `-b` | Путь к BOM-файлу (.xlsx) |
| `--cards` | `-c` | Папка/ZIP с операционными картами |
| `--output` | `-o` | Директория результатов (default: `./output`) |
| `--single-config` | `-s` | Режим одной комплектации |
| `--config` | `-k` | Название комплектации (для --single-config) |
| `--no-split` | | Не разделять карты |
| `--no-fuzzy` | | Отключить нечёткое сравнение |
| `--workers` | `-w` | Количество процессов (default: auto) |
| `--verbose` | `-v` | Подробный лог |

### Режимы

- **По умолчанию** — обработка всех комплектаций одновременно с построением полной матрицы расхождений
- `--single-config` — только одна комплектация (интерактивный выбор или `--config`)

### Вывод

1. `report.txt` — текстовый отчёт
2. `discrepancies.xlsx` — 4 листа: сводка, сводка по комплектациям, расхождения, fuzzy matches
3. `split_cards/` — разделённые однолистовые файлы
4. `split_cards.zip` — архив

## Архитектура

```
burlak_parser/
├── __init__.py
├── main.py              # CLI, конвейер
├── bom_parser.py        # BOMService — парсинг BOM
├── card_parser.py       # CardService — парсинг карт
├── file_classifier.py   # FileClassifier — классификация файлов
├── fuzzy_matcher.py     # FuzzyMatcher — нечёткое сравнение
├── splitter.py          # CardSplitter — ZIP-разделение листов
├── comparator.py        # MatchingEngine — сверка BOM и карт
└── report_generator.py  # Reporter — Excel-отчёты
```

### Сервисы

| Сервис | Назначение |
|--------|------------|
| BOMService | Загрузка и парсинг BOM-файлов |
| CardService | Загрузка и парсинг операционных карт |
| FileClassifier | Классификация: операционная карта или служебный файл |
| FuzzyMatcher | Безопасное нечёткое сравнение номеров |
| CardSplitter | ZIP-разделение многолистовых файлов |
| MatchingEngine | Сверка BOM и карт, все комплектации |
| Reporter | Генерация отчётов (XLSX, TXT, ZIP) |

## Как это работает

### Классификация файлов

Перед парсингом каждый файл классифицируется:
- **Операционные карты** — имя начинается с номера операции (038-Установка, A123-Контроль, SQRT1L-A-AS-038)
- **Служебные файлы** — имя содержит 封面, 目录, 记录表, 空表

### Парсинг BOM

Автоматическое определение колонок и VIN-фильтрация. Загрузка через openpyxl с read_only=True.

### Парсинг карт

Универсальный загрузчик (xlsx / xls). Поиск таблицы деталей, склейка перенесённых номеров, суммирование. Параллельное выполнение через ProcessPoolExecutor.

### ZIP-разделение

Метод «удаления лишнего»: копия исходного файла, из ZIP-структуры удаляются все листы, кроме целевого. Сохраняется 100% форматирования. Очистка named ranges для предотвращения ошибки Excel «Removed Feature: Named range».

### Fuzzy matching

Безопасное сравнение: номера считаются совпавшими, если они идентичны после удаления дефисов, пробелов, точек и спецсимволов. Различие хотя бы в одной цифре или букве — не совпадение.

### Сверка всех комплектаций

Построение общего fuzzy-индекса, для каждой комплектации — матрица расхождений: только в BOM, только в картах, конфликт количества, fuzzy match.

### Отчёт

4 листа: сводка, по комплектациям, расхождения, fuzzy matches.

## Пример

```python
from burlak_parser.bom_parser import BOMService
from burlak_parser.card_parser import CardService
from burlak_parser.comparator import MatchingEngine

bom = BOMService()
bom.load("/path/to/bom.xlsx")

cards = CardService()
cards.load("/path/to/cards/")

engine = MatchingEngine(use_fuzzy=True)
result = engine.compare(bom.bom, cards.cards)
```
