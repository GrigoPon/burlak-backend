# Burlak Parser

Система разбора ведомостей материалов (BOM) и сверки с операционными картами сборки для автомобильного производства.

Поддержка вложенных ZIP-архивов с рекурсивным извлечением. Дедупликация файлов по сигнатуре (размер + содержимое). Профессиональный дашборд в Excel-отчёте с карточками метрик.

---

## Установка

```
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
pip install xlrd
```

Зависимости: openpyxl, xlsxwriter, tqdm.

---

## Использование

```
python -m burlak_parser.main --bom "BOM.xlsx" --cards "./cards/" [OPTIONS]
```

### Параметры

| Параметр | Описание |
|----------|----------|
| `--bom` | Путь к BOM-файлу (.xlsx) |
| `--cards` | Папка/ZIP с операционными картами |
| `--output` | Директория результатов |
| `--single-config` | Режим одной комплектации |
| `--config` | Название комплектации |
| `--no-split` | Не разделять карты |
| `--no-fuzzy` | Отключить нечёткое сравнение |
| `--workers` | Количество процессов |
| `--verbose` | Подробный лог |

## Как это работает

### Поиск файлов

Функция `_find_excel_files()`:
- Рекурсивно извлекает ZIP-архивы, включая вложенные (архив внутри архива)
- Дедуплицирует файлы по сигнатуре: размер файла + первые 4096 байт
- Фильтрует временные файлы (~$) и не-Excel форматы
- Извлечённые файлы помещаются во временную директорию, которая очищается после завершения

### Отчёт

Лист «Сводка» переработан в дашборд:
- Шапка с мета-информацией (количество комплектаций, деталей в BOM и картах)
- Карточки метрик: всего несоответствий, разное количество, только в BOM, только в картах
- Строка с количеством обработанных и повреждённых файлов
- Таблица по комплектациям с чередованием цвета строк

Терминология расхождений:
- «Есть в BOM, нет в операционных картах»
- «Есть в операционных картах, нет в BOM»
