# Burlak Parser

Система разбора ведомостей материалов (BOM) и сверки с операционными картами сборки для автомобильного производства.

Эвристический анализатор структуры документа для автоматического определения колонок (артикул, количество, название) по заголовкам на трёх языках: русском, английском, китайском. Позволяет обрабатывать BOM от разных поставщиков без ручной настройки.

---

## Установка

```
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
pip install xlrd
```

Зависимости: openpyxl, xlsxwriter, tqdm.

---

## Использование

```
python -m burlak_parser.main --bom "BOM.xlsx" --cards "./cards/" [OPTIONS]
```

### Параметры

| Параметр | Описание |
|----------|----------|
| `--bom` | Путь к BOM-файлу (.xlsx) |
| `--cards` | Папка/ZIP с операционными картами |
| `--output` | Директория результатов |
| `--single-config` | Режим одной комплектации |
| `--config` | Название комплектации |
| `--no-split` | Не разделять карты |
| `--no-fuzzy` | Отключить нечёткое сравнение |
| `--workers` | Количество процессов |
| `--verbose` | Подробный лог |

## Эвристический анализатор

Модуль `heuristic_analyzer.py` определяет структуру Excel-документа динамически, без привязки к конкретным индексам колонок или брендам.

### Определение колонок

Анализатор сканирует заголовки (первые строки листа) и сопоставляет их с ключевыми словами:

| Категория | RU | EN | CN |
|-----------|-----|-----|------|
| Номер детали | номер, артикул, код, деталь, обозначение | part no, part number, p/n, code | 件号, 图号, 零件号, 代号 |
| Количество | кол-во, количество | qty, quantity | 数量, 用量 |
| Название | наименование, название, описание | name, description, part name | 名称, 描述 |

### Алгоритм

1. `find_header_rows` — поиск строки заголовков по ключевым словам
2. `detect_column_types` — классификация колонок (part_no, name, qty, config, meta)
3. `find_data_region` — определение границ таблицы данных
4. Если заголовки не найдены — позиционные эвристики (первая колонка с кодом = артикул, первая числовая = количество)
5. Возврат конфигурации колонок с уровнем уверенности (confidence)

### Интеграция

Используется `bom_parser` и `card_parser` как альтернатива жёсткому определению колонок. Позволяет обрабатывать BOM от разных производителей без изменения кода.
