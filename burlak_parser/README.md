# Burlak Parser

Система разбора ведомостей материалов (BOM) и сверки с операционными картами сборки.

Сопоставляет каталожные номера деталей из BOM-файла с номерами в операционных картах сборки. Выявляет расхождения, включая нечёткие совпадения номеров (разный формат записи).

Поддерживает фильтрацию шаблонных и служебных листов (封面, 目录, 记录表, 空表). Многолистовые файлы разделяются параллельно через ProcessPoolExecutor.

---

## Установка

```
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
pip install xlrd
```

Зависимости: openpyxl, pandas, xlsxwriter, tqdm.

---

## Использование

```
python -m burlak_parser.main --bom "BOM.xlsx" --cards "./cards/" [OPTIONS]
```

### Параметры

| Параметр | Описание | По умолчанию |
|----------|----------|-------------|
| `--bom` | Путь к BOM-файлу (.xlsx) | обязательный |
| `--cards` | Папка/ZIP с картами | обязательный |
| `--config` | Название комплектации | интерактивный выбор |
| `--output` | Директория результатов | `./output` |
| `--skip-templates` | Фильтровать шаблонные листы | True |
| `--no-skip-templates` | Не фильтровать шаблоны | — |
| `--no-fuzzy` | Отключить нечёткое сравнение | — |
| `--no-split` | Не разделять карты | — |
| `--verbose` | Подробный лог | — |

### Вывод

1. `report.txt` — текстовый отчёт
2. `discrepancy_report.xlsx` — Excel-отчёт (с колонкой fuzzy-совпадений)
3. `split_cards/` — разделённые однолистовые файлы
4. `split_cards.zip` — архив

## Нечёткое сравнение номеров

Модуль `comparator.py` реализует fuzzy matching через difflib.SequenceMatcher:

- **Нормализация:** из номера удаляются дефисы, пробелы, точки, слеши и спецсимволы
- **Сравнение:** вычисляется ratio() двух нормализованных строк
- **Типы:** FUZZY_IN_BOM (номер в BOM не совпадает точно, но есть кандидат в картах) и FUZZY_IN_CARDS (номер в картах не совпадает точно, но есть кандидат в BOM)
- **Управление:** флаг `--no-fuzzy` отключает нечёткое сравнение

## Фильтрация шаблонов

Функция `_is_template_sheet()` определяет служебные листы по ключевым словам: 空表, 封面, 目录, 记录表, Sheet1. Управляется флагом `--skip-templates`.

## Параллельное разделение

Разделение многолистовых файлов выполняется через ProcessPoolExecutor. Количество процессов определяется автоматически. Функция `_split_single_sheet()` вынесена как picklable для передачи в процессы.

## Как это работает

### Парсинг BOM

Автоматическое определение колонок. Исключение VIN-колонок (содержат S/-). Поддержка xlsx и xls.

### Парсинг карт

Поиск таблицы деталей, склейка перенесённых номеров, суммирование повторений. Фильтрация шаблонных листов. Загрузка через openpyxl с fallback на xlrd.

### Разделение листов

Прямая манипуляция ZIP-структурой xlsx. Полное сохранение форматирования. Параллельное выполнение.

### Сверка

Пять типов расхождений: ONLY_IN_BOM, ONLY_IN_CARDS, QUANTITY_MISMATCH, FUZZY_IN_BOM, FUZZY_IN_CARDS.

### Отчёт

Excel-отчёт с колонкой fuzzy-совпадений и отдельным листом для нечётких совпадений.
