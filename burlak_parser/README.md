# Burlak Parser

Система разбора ведомостей материалов (BOM) и сверки с операционными картами сборки.

Сопоставляет каталожные номера деталей из BOM-файла с номерами в операционных картах сборки (xlsx/xls). Выявляет расхождения: детали, отсутствующие в картах, лишние детали, несоответствия количества.

BOM может содержать как реальные комплектации (с числовыми значениями количества), так и VIN-колонки (со значениями S / -). Парсер автоматически определяет границу и исключает VIN-разбивку, оставляя только фактические комплектации.

Многолистовые xlsx-файлы карт разделяются на отдельные листы с полным сохранением форматирования через прямую манипуляцию ZIP-структурой.

## Установка

```
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
pip install xlrd
```

Зависимости: openpyxl, pandas, xlsxwriter, tqdm.

---

## Использование

```
python -m burlak_parser.main --bom "BOM.xlsx" --cards "./cards/" [--config <name>]
```

### Параметры

| Параметр | Описание |
|----------|----------|
| `--bom` | Путь к BOM-файлу (.xlsx) |
| `--cards` | Папка с картами или ZIP-архив |
| `--config` | Название комплектации (без флага — интерактивный выбор) |
| `--output` | Директория результатов (default: `./output`) |
| `--no-split` | Не разделять карты |
| `--verbose` | Подробный лог |

### Вывод

1. `report.txt` — текстовый отчёт
2. `discrepancy_report.xlsx` — Excel-отчёт (3 листа: сводка, расхождения, все детали BOM)
3. `split_cards/` — разделённые однолистовые файлы
4. `split_cards.zip` — архив разделённых файлов

## Как это работает

### Парсинг BOM

Модуль `bom_parser.py` находит строку заголовка по ключевым словам (零件号, PartNo), определяет колонки парт-номера, названий и комплектаций.

**Определение комплектаций:** парсер находит все колонки справа от парт-номера, проверяет их содержимое на числовые значения. Колонки, содержащие только `S` (Same) и `-` (не применимо) — VIN-разбивка — автоматически исключаются. Остаются только реальные комплектации с количеством деталей.

### Парсинг операционных карт

`card_parser.py` — универсальный загрузчик (xlsx через openpyxl, xls через xlrd с авто-выбором). Для каждого файла определяет номер карты, ищет таблицу деталей по ключевым словам, извлекает парт-номер, количество, название. Склеивает перенесённые номера (строка заканчивается на `-` → продолжается на следующей). Повторяющиеся детали в разных листах/картах суммируются.

### Разделение листов

Используется метод прямой манипуляции ZIP: исходный xlsx копируется побайтово, из ZIP-архива удаляются все листы, кроме целевого. Сохраняется 100% форматирования: изображения, стили, объединённые ячейки, ширина/высота, закреплённые области, параметры страницы.

### Сверка

Три типа расхождений: только в BOM, только в картах, конфликт количества.

### Отчёт

Текстовый отчёт + Excel-отчёт с цветовой кодировкой (жёлтый — только в BOM, голубой — только в картах, розовый — конфликт количества) + ZIP-архив.
