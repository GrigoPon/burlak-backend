# Burlak Parser

Система разбора ведомостей материалов (BOM) и сверки с операционными картами сборки.

Сопоставляет каталожные номера деталей из BOM-файла с номерами в операционных картах сборки (xlsx/xls). Выявляет расхождения: детали, отсутствующие в картах, лишние детали, несоответствия количества.

Многолистовые xlsx-файлы карт разделяются на отдельные листы с полным сохранением форматирования — изображения, стили, объединённые ячейки, параметры страницы.

---

## Установка

```
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
pip install xlrd
```

Зависимости: openpyxl, pandas, xlsxwriter, tqdm.

---

## Использование

```
python -m burlak_parser.main --bom "BOM.xlsx" --cards "./cards/" [--config <name>]
```

### Параметры

| Параметр | Описание |
|----------|----------|
| `--bom` | Путь к BOM-файлу (.xlsx) |
| `--cards` | Путь к папке с картами или ZIP-архиву |
| `--config` | Название комплектации (без флага — интерактивный выбор) |
| `--output` | Директория для результатов (по умолч. `./output`) |
| `--no-split` | Не разделять многолистовые карты |
| `--verbose` | Подробный вывод (debug) |

### Вывод

1. `report.txt` — текстовый отчёт
2. `discrepancy_report.xlsx` — Excel-отчёт (3 листа)
3. `split_cards/` — разделённые однолистовые файлы
4. `split_cards.zip` — архив разделённых файлов

## Разделение листов

Система использует два метода разделения многолистовых xlsx-файлов:

**Основной (прямая манипуляция ZIP).** xlsx-файл является ZIP-архивом XML-файлов. Метод копирует исходный файл целиком, затем удаляет из ZIP-структуры все листы, кроме целевого. Это сохраняет 100% оригинального форматирования: шрифты, цвета, границы, заливки, выравнивание, объединённые ячейки, ширина колонок, высота строк, закреплённые области, изображения, настройки страницы.

**Резервный (через openpyxl).** Если ZIP-метод не сработал (например, повреждённый файл), создаётся новый Workbook и каждому элементу копируются стили с помощью deepcopy.

Порядок работы: сначала пробуется ZIP-метод, при ошибке — openpyxl.

## Как это работает

### Шаг 1: Парсинг BOM

`bom_parser.py` читает xlsx-файл спецификации, находит строку заголовка по ключевым словам (零件号, PartNo), определяет колонки каталожного номера, названий и комплектаций.

### Шаг 2: Парсинг операционных карт

`card_parser.py` обходит файлы в папке или ZIP-архиве. Определяет номер карты, ищет таблицу деталей по ключевым словам, извлекает парт-номер, количество, название. Склеивает перенесённые номера, суммирует повторения.

### Шаг 3: Сверка

`comparator.py` — три типа расхождений: только в BOM, только в картах, конфликт количества.

### Шаг 4: Отчёт

`report_generator.py` — текстовый отчёт, Excel-отчёт с цветовой кодировкой, ZIP-архив.
