# Burlak Parser

Система разбора ведомостей материалов (BOM) и сверки с операционными картами сборки для автомобильного производства.

Многотабличный парсинг: обнаружение границ разделов на одном листе — каждая таблица парсится отдельно. Обработка файлов с искажёнными именами из-за проблем с кодировкой. Полный набор модульных тестов (7 файлов, покрытие всех модулей).

```
pip install -r requirements.txt

```

## Использование

```
python -m burlak_parser.main --bom "BOM.xlsx" --cards "./cards/" [OPTIONS]
```

### Параметры

| Параметр | Описание |
|----------|----------|
| `--bom` | Путь к BOM-файлу (.xlsx) |
| `--cards` | Папка/ZIP с операционными картами |
| `--output` | Директория результатов |
| `--single-config` | Режим одной комплектации |
| `--config` | Название комплектации |
| `--no-split` | Не разделять карты |
| `--no-fuzzy` | Отключить нечёткое сравнение |
| `--workers` | Количество процессов |
| `--verbose` | Подробный лог |

## Многотабличный парсинг

Функция `_collect_all_tables()` обнаруживает границы разделов на листе. Если лист содержит несколько таблиц (например, несколько операций с деталями), каждая таблица обрабатывается отдельно. Граница определяется по:
- Появлению нового заголовка колонок (ключевые слова 件号, part no и т.д.)
- Трём и более пустым строкам подряд внутри таблицы

## Обработка искажённых имён

Некоторые файлы имеют искажённые имена из-за проблем с кодировкой (например, `5. G01Pш╜ж▓W5.xlsx`). Регулярное выражение `CARD_NUMBER_ANYWHERE_RE` находит номер карты в любой части имени файла, игнорируя нечитаемые символы.

## Эвристический анализатор — улучшения

- В список исключаемых ключевых слов добавлены «серийный», «serial»
- Порог уверенности снижен до 0.25 для большего количества срабатываний
- Максимальная ширина сканируемой области ограничена 40 колонками
- Поиск таблицы поддерживает параметр start_row и сканирует строки выше и ниже заголовка
