# Burlak Parser

Система разбора ведомостей материалов (BOM) и сверки с операционными картами сборки.

Сопоставляет каталожные номера деталей из BOM-файла с номерами в операционных картах сборки (xlsx/xls). Выявляет расхождения: детали, отсутствующие в картах, лишние детали, несоответствия количества.

---

## Установка

```
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
pip install xlrd
```

Зависимости: openpyxl, pandas, xlsxwriter, tqdm.

---

## Использование

```
python -m burlak_parser.main --bom "BOM.xlsx" --cards "./cards/" [--config <name>]
```

### Параметры

| Параметр | Описание |
|----------|----------|
| `--bom` | Путь к BOM-файлу (.xlsx) |
| `--cards` | Путь к папке с картами или ZIP-архиву |
| `--config` | Название комплектации (без флага — интерактивный выбор) |

### Режимы

По умолчанию — одна комплектация. Можно указать `--config` для выбора без интерактива.

### Вывод

Артефакты в `./output/`:
1. `report.txt` — текстовый отчёт о расхождениях
2. `discrepancy_report.xlsx` — Excel-отчёт (3 листа: сводка, расхождения, все детали BOM)
3. `split_cards/` — разделённые однолистовые файлы
4. `split_cards.zip` — архив разделённых файлов

## Как это работает

### Шаг 1: Парсинг BOM

Модуль `bom_parser.py` читает xlsx-файл спецификации, ищет строку заголовка по ключевым словам (零件号, PartNo), определяет колонки: каталожный номер, название (кит.), название (англ.), колонки комплектаций.

### Шаг 2: Парсинг операционных карт

Модуль `card_parser.py` обходит xlsx/xls файлы в указанной папке или ZIP-архиве. Для каждого файла:
- Определяет номер карты по шаблону в содержимом или имени файла
- Проверяет листы — пустые пропускаются
- Ищет таблицу деталей по ключевым словам (料号, 零件号, 用量, qty)
- Извлекает парт-номер, количество, название
- Склеивает перенесённые номера (если строка заканчивается на `-`)
- Суммирует повторяющиеся детали в разных листах/картах

### Шаг 3: Разделение многолистовых файлов

Каждый многолистовой xlsx преобразуется в набор отдельных файлов (один лист = один файл). Пропускаются пустые листы. xls-файлы не разделяются.

### Шаг 4: Сверка

Модуль `comparator.py` сопоставляет детали по каталожному номеру. Типы расхождений:
- Только в BOM — деталь есть в спецификации, не найдена в картах
- Только в Картах — деталь есть в картах, отсутствует в BOM
- Конфликт количества — количество в картах не совпадает с BOM

### Шаг 5: Отчёт

Модуль `report_generator.py` формирует текстовый отчёт, Excel-отчёт с цветовой кодировкой расхождений, ZIP-архив разделённых карт.
